## `02` About

I build full-stack web applications using the MERN stack, with React and Next.js on the frontend and Node.js with Express on the backend. I work with MongoDB and MySQL for data-driven applications and enjoy building real-time systems, REST APIs, authentication flows, and responsive user experiences.

Currently, I'm strengthening my TypeScript and Next.js skills, exploring backend architecture beyond basic CRUD, and improving my understanding of CI/CD and cloud deployment.

I learn by building real applications and exploring how modern products are designed, structured, deployed, and scaled.
